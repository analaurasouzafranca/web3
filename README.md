
```
npm install
node --watch app.js
```
Abra http://localhost:3000



## Componentes UIkit usados
- Fundo: `uk-background-cover` (home)
- Ícone: `uk-icon` (navbar, cards, editar/excluir)
- Rolar: `uk-scroll` (voltar ao topo) e `uk-scrollspy`
- Imagem: `uk-cover` (foto do artista)
- Lista: `uk-list` (listagens e detalhes)
